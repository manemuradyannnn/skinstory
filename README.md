# SkinStory

A personal journal for skin changes. Photograph a concern, mark where it is, keep what you notice, and prepare a summary for a dermatologist visit.

SkinStory records observations. It does not diagnose, score risk, or suggest treatment.

Photos and notes stay in the browser tab. Refreshing the page clears anything you add. The concerns marked Sample are fictional.

## Run

```bash
npm install
npm run dev
```

Then open the local address Vite prints.

```bash
npm test
npm run build
```
