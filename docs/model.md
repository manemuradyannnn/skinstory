# Model and data

CellScope runs one model, on one kind of image.

## Model

| | |
| --- | --- |
| Name | StarDist `2D_versatile_fluo` |
| Software | [stardist/stardist](https://github.com/stardist/stardist), version 0.9.2 |
| Software licence | BSD-3-Clause |
| Weights | [python_2D_versatile_fluo.zip](https://github.com/stardist/stardist-models/releases/download/v0.1/python_2D_versatile_fluo.zip) from the StarDist model release `v0.1` |
| Local cache | `~/.keras/models/StarDist2D/2D_versatile_fluo/` |
| Domain | 2D fluorescence microscopy of a nuclear marker, single channel |
| Not supported | H&E histology, brightfield, 3D, TIFF, clinical diagnosis |
| Input | PNG or JPEG. EXIF orientation is applied. Colour is reduced to luminance. Normalisation is `csbdeep.utils.normalize` with percentiles 3 and 99.8, matching the project’s pretrained-model example. |
| Thresholds | Taken from the weight bundle: object probability about 0.479, non-maximum suppression 0.3 |
| Output | Instance polygons (32 rays), centres, boxes, and object probability |

StarDist’s own documentation describes `2D_versatile_fluo` as trained on a subset of the DSB 2018 nuclei segmentation challenge. CellScope does not redistribute that dataset. The H&E model `2D_versatile_he` is a different network and is not loaded.

Cite, if you use the method:

- Uwe Schmidt, Martin Weigert, Coleman Broaddus, and Gene Myers. *Cell Detection with Star-Convex Polygons.* MICCAI 2018. https://doi.org/10.1007/978-3-030-00934-2_30
- Martin Weigert, Uwe Schmidt, Robert Haase, Ko Sugawara, and Gene Myers. *Star-convex Polyhedra for 3D Object Detection and Segmentation in Microscopy.* WACV 2020. https://doi.org/10.1109/WACV45572.2020.9093435

The dependency `csbdeep` is the CSBDeep library used by StarDist for normalisation.

## Images shipped with this prototype

Both image sets are generated by `backend/app/synthetic.py`. They are fictional fluorescence fields, not laboratory acquisitions.

- Workspace sample: seed 11, 1120×800, `frontend/public/samples/fluorescence-nuclei.png`. The review fixture’s contours are the 2σ ellipses of the Gaussians used to paint the nuclei.
- Validation split: seed 7, six 384×288 images, each with one touching pair. Ground-truth masks use the same 2σ contour. The workspace sample is not part of this split.

## Metrics that are stored

`backend/data/evaluation/report.json` is the output of `python scripts/evaluate.py` with StarDist 0.9.2 and TensorFlow 2.21 on CPU. Detection uses greedy one-to-one matching at mask IoU ≥ 0.5. Counting error is the mean absolute count difference and is not the same number. These figures are not a claim about real micrographs.
